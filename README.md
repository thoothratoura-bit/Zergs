# ミドリ島の勇者 〜光の結晶をもとめて〜

スマホのブラウザでそのまま遊べる、見下ろし型のアクションアドベンチャーゲームです。
剣で魔物をたおし、洞窟や遺跡を探索して、岩の魔人にうばわれた「光の結晶」をとりもどしましょう。

HTML / CSS / JavaScript だけで作っていて、画像・音声ファイルは使っていません
（ドット絵・効果音・BGM はすべてコードで生成しています）。

## 遊び方

### スマホ
| 操作 | 内容 |
| --- | --- |
| 左側をドラッグ | 移動（バーチャルスティック。触れた場所が中心になります） |
| **A** ボタン | 剣でこうげき／人と話す・看板を読む／会話を進める |
| **A** 長押し → はなす | 回転斬り |
| **B** ボタン | アイテムを使う（ブーメラン・爆弾） |
| ⇄ 切替 | B ボタンのアイテムを切りかえ |
| ≡ ポーズ | ポーズ画面（地図・もちもの） |
| ♪ | 音のオン／オフ |

縦画面・横画面のどちらでも遊べます。ホーム画面に追加すると全画面で遊べます。

### PC（キーボード）
| キー | 内容 |
| --- | --- |
| 矢印キー / WASD | 移動 |
| Z / J / Space | A ボタン |
| X / K | B ボタン |
| C / Shift | アイテム切替 |
| Enter / Esc | ポーズ |
| M | 音のオン／オフ |

## ゲームの内容

- **フィールド**: 12 画面の島（草原・森・山・湖・浜辺・砂漠）
- **洞窟**: 長老の洞窟、道具屋、ひみつの洞窟
- **ダンジョン**: カギ・カギ扉・シャッター扉・ボス扉のある 7 部屋の遺跡
- **アイテム**: 剣、ブーメラン（敵をしびれさせる／遠くのアイテムを取る）、爆弾（ひび割れた壁や岩をこわす）、ハートの器（全 4 個）
- **敵**: スライム、コウモリ、オニ（石を投げる）、ガイコツ、ボスの「岩の魔人 ゴロム」
- 進行状況はブラウザに自動セーブされます（タイトル画面の「つづきから」）

### ヒント
- 最初は、スタート地点のすぐ近くにある洞窟へ行ってみましょう。
- 遺跡の前のしげみは剣で切れます。
- 爆弾は山の道具屋で買えます。ジェムは魔物をたおすと手に入ります。
- 取れない場所にあるアイテムは、ブーメランで取ってこられるかも…？

## GitHub Pages で公開する

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch でこのゲームが入っているブランチ（例: `main`）と `/ (root)` を選んで **Save**
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります
   （このリポジトリなら `https://thoothratoura-bit.github.io/Zergs/`）

## ローカルで遊ぶ

`index.html` をブラウザで開くだけで動きます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体（画面とタッチ用ボタン） |
| `style.css` | レイアウト（縦画面／横画面対応） |
| `game.js` | ゲーム本体（マップ・敵・ドット絵・サウンドなど） |
| `manifest.json`, `icon.svg` | ホーム画面に追加したとき用の設定とアイコン |
